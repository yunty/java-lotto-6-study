## 📋 기능 목록

### 1. 입력

- [ ] [구입금액]을 입력받는다.
    - 입력 형식: `[1000원 단위]`
- [ ] [당첨번호]를 입력받는다.
  - 입력 형식: `[쉼표기준, 6자리]
- [ ] [보너스 번호]를 입력받는다.
  - 입력 형식: `[1부터 45까지 당첨번호와 중복되지 않는 숫자]

### 2. 핵심 기능

- [ ] [구입 금액에 맞춰서 로또 구매]를 수행한다.
    - 적용 규칙: [로또 1장에는 중복되지 않는 숫자 6개]
- [ ] [당첨번호와 비교하여 결과 판독]을 수행한다.
    - 적용 규칙
      - 3개 일치시 5,000
      - 4개 일치시 50,000
      - 5개 일치시 1,500,000
      - 5개 + 보너스 번호 일치 시 30,000,000
      - 6개 일치 시 2,000,000,000
- [ ] [수익률 계산]을 수행한다.
- [ ] [종료 조건]을 만족하면 실행을 종료한다.

### 3. 출력

- [ ] [사용자에게 필요한 안내]를 출력한다.
  - 구입 금액 입력 안내 출력
    - 출력 형식 : [구입금액을 입력해 주세요.]
  - 구매 장수 출력
    - 출력 형식 : [3개를 구매했습니다.]
  - 구매 로또 번호 출력
    - 출력 형식 : [1, 2, 3, 4, 5, 6]
  - 당첨 번호 입력 안내 출력
    - 출력 형식 : [당첨 번호를 입력해 주세요.]
  - 보너스 번호 입력 안내 출력
    - 출력 형식 : [보너스 번호를 입력해 주세요.]
  - [ ] [최종 결과]를 지정된 형식으로 출력한다.
    - 출력 형식
        - [당첨통계]
        - [---]
        - [3개 일치 (5,000원) - 1개]
        - [4개 일치 (50,000원) - 0개]
        - [5개 일치(1,500,000원) - 0개]
        - [5개 일치, 보너스 볼 일치 (30,000,000원) - 0개]
        - [6개 일치 (2,000,000,000원) - 0개]
        - [총 수익률은 62.5%입니다.]
      - 출력 형식: `[출력 예시]`

### 4. 예외 처리

- [ ] 입력값 예외 적용
  - [ ] Null값
  - [ ] Empty
- [ ] 구입 금액 예외
  - [ ] 금액 % 1000 !=0
- [ ] 로또 번호 예외
  - [ ] split 이후 배열의 길이 6이 아닌것
  - [ ] 중복되는 숫자
  - [ ] ","로 구분되지 않는 값
  - [ ] 빈값
- [ ] 보너스 번호 예외
  - [ ] 1부터 45의 숫자가 아닌 값
  - [ ] 당첨번호와 중복되는 값
